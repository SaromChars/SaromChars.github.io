低精度表示与模型部署

2022年4月29日
|

在神经网络落地部署的工程实践中，模型往往面临严苛的硬件资源限制，权重与激活值通常采用 32 位单精度浮点数（single-precision floating point，FP32）存储与计算1 (§1)。在边缘设备（如智能手机与移动嵌入式芯片）上，高位宽浮点计算不仅占用大量片上存储，而且在推理（inference）阶段受限于片外内存读写的访存带宽瓶颈。若硬件配备高效的单指令多数据（single instruction, multiple data，SIMD）整型单元，纯浮点执行便难以发挥这些硬件的计算潜力。

为了突破硬件吞吐限制，将浮点权重与激活值转换为低位宽整数的低精度表示（low-precision representation），即模型量化（quantization），成为工业界部署的关键路径。Jacob et al. (2017) 提出了纯整型算术推理（integer-arithmetic-only inference）与模拟量化训练（training with simulated quantization，即量化感知训练，quantization-aware training，QAT）的完整框架1 (Abstract, §1)。本文基于该论文固定版本（arXiv:1712.05877v1），解析整型仿射量化映射、纯整型矩阵乘法实现、训练期伪量化机制，并结合其在经典视觉网络上的实验证据，剖析低精度部署的物理收益与有效边界。

1. 仿射量化方案与零点对齐

模型量化的核心目标是建立实数连续域与低位宽离散整数域之间的双向数学映射，同时保证硬件计算能够完全使用整型指令高效完成1 (§2.1)。

1.1 仿射映射公式

为了避免在硬件 SIMD 指令中引入代价高昂的查表操作，Jacob et al. (2017) 采用基于仿射变换（affine mapping）的非对称量化方案。对于给定的量化整数 q（quantized integer），其映射解释的重建实数值 r_hat 满足以下关系1 (§2.1, 式 1)：

r_hat = S * (q - Z)

原始连续实数 r（real value）在量化过程中经过截断钳位和取整映射为整数 q，因此反量化后的 r_hat 通常是对原实数的近似重建。映射公式中包含两个关键量化参数：

  • 缩放因子（scale factor，S）：一个任意的正实数，代表量化网格中单个量化步长所对应的实数跨度；
  • 零点（zero-point，Z）：与量化整数 q 具有相同数据类型（如 uint8 或 int8）的整数常数。

在 8 位量化方案中，q 通常取 8 位无符号整数（uint8，范围 [0, 255]）或有符号整数（int8，范围 [-128, 127]）。神经网络中每个张量（例如某层的权重矩阵或激活值张量）共享一组独立的 (S, Z) 参数1 (§2.1)。

1.2 零点的精确表示

该论文特别强调零点 Z 必须能让实数值 r = 0.0 被精确表示为整数 q = Z1 (§2.1)。

这一要求源于深度学习算子的工程特性。在神经网络中，边界零填充（zero-padding）是极其普遍的操作；同时，修正线性单元（rectified linear unit，ReLU）等常见激活函数也会产生大量精确的 0.0。如果实数 0.0 无法精确映射为整数，零填充区域在反量化时就会引入非零系统误差1 (§2.1)。

2. 纯整型算术矩阵乘法的推导与消除开销

如果仅仅将参数存储为 8 位整数，但在推理运行时先反量化回浮点数再做矩阵乘法，便只能节省存储空间，无法享受整型硬件单元的算力红利。该量化方案的关键突破在于将矩阵乘法完全转换为纯整型计算1 (§2.2)。

2.1 矩阵乘法的量化推导

考虑权重矩阵 r_1 与输入激活矩阵 r_2 相乘得到输出激活矩阵 r_3：r_3 = r_1 * r_2。各自对应的量化参数为 (S_1, Z_1)、(S_2, Z_2) 与 (S_3, Z_3)1 (§2.2, 式 2)。

根据仿射量化定义，将各矩阵元素代入矩阵乘法定义式：

S_3 * (q_3^(i,k) - Z_3) = sum_{j=1}^N S_1 * (q_1^(i,j) - Z_1) * S_2 * (q_2^(j,k) - Z_2)

两边同除以 S_3，并整理出输出量化整数 q_3^(i,k) 的表达式1 (§2.2, 式 4)：

q_3^(i,k) = Z_3 + M * sum_{j=1}^N (q_1^(i,j) - Z_1) * (q_2^(j,k) - Z_2)

其中组合乘数标量 M 定义为1 (§2.2, 式 5)：

M = (S_1 * S_2) / S_3

2.2 乘数 M 的定点化与移位消除

在公式中，输入激活与权重的量化整数 q_2、q_1 以及零点 Z_1、Z_2、Z_3 均为纯整数。唯一的非整数项是乘数 M，它由三个实数缩放因子计算得到1 (§2.2)。

在模型推理执行前，量化参数由训练得到的范围固定，因此 M 可以在离线时预先计算。论文作者在经验上观察到 M 处于区间 (0, 1) 之内，因此可将其标准化分解为1 (§2.2, 式 6)：

M = 2^(-n) * M_0

其中：

  • M_0 是一个处于区间 [0.5, 1.0) 内的实数归一化乘数；
  • n 是非负整数指数。

当采用 32 位整型（Q31 格式）定点表示时，可使用最接近 2^31 * M_0 的 32 位有符号整数编码 K ≈ round(2^31 * M_0)。由于 M_0 >= 0.5，整数编码 K 至少大于等于 2^30，始终保留至少 30 位的相对精度。在线推理时，乘以 M_0 对应硬件高效的 32 位定点乘法，而乘以 2^(-n) 则通过正确实现最近舍入的右移操作完成（附录 B 提示需修正普通右移的舍入行为）1 (§2.2, Appendix B)。至此，前向传播中完全移除了浮点数运算。

2.3 零点消除与计算复杂度分离

如果直接计算 (q_1 - Z_1) * (q_2 - Z_2)，每次内积累加都需要两次减法，或者需要将 8 位数扩展为 16 位以防下溢，带来极高的运算冗余。

通过展开乘积多项式，公式可等价改写为1 (§2.3, 式 7)：

q_3^(i,k) = Z_3 + M * [ N * Z_1 * Z_2 - Z_1 * a_2^(k) - Z_2 * a_1^(i) + sum_{j=1}^N q_1^(i,j) * q_2^(j,k) ]

其中引入的求和辅助项为1 (§2.3, 式 8)：

a_2^(k) = sum_{j=1}^N q_2^(j,k),    a_1^(i) = sum_{j=1}^N q_1^(i,j)

这项代数变换具有明确的工程价值：

  1. 核心乘累加是纯整型：内积核心 sum_{j=1}^N q_1^(i,j) * q_2^(j,k) 的复杂度为 O(N^3)，底层直接实现为紧凑的 int32 += uint8 * uint8，无每次乘法前额外的减法开销；
  2. 辅助项复杂度仅为 O(N^2)：a_2^(k) 与 a_1^(i) 的求和开销仅为 O(N^2)，且权重端的行和 a_1^(i) 可以在离线部署时预先计算完毕；
  3. 偏置项（bias）使用 32 位整型：偏置向量若量化为 8 位，同一偏置条目重复加到多个输出激活上，可能造成非零均值的系统性误差。因此偏置向量统一量化为 int32，其量化参数设为 S_bias = S_1 * S_2 且 Z_bias = 0，正好与累加器位宽一致，直接以纯整型加法合入1 (§2.4, 式 11)。

3. 核心算术数据流示意

在实际推理引擎（如 TensorFlow Lite 及底层 gemmlowp 库）中，矩阵乘法、偏置累加、定点缩放与非线性激活被融合执行，输入与输出均为 8 位量化整数1 (§2.4)。

4. 训练后量化的失效原因与模拟量化训练

在工程落地中，一种直观做法是对已训练好的浮点模型参数直接做离散化，即训练后量化（post-training quantization，PTQ）1 (§3)。论文作者观察到，这种简单量化对某些具备充裕表征容量的过参数化大型模型尚可维持可用精度，但在追求紧凑高效的轻量模型（如 MobileNet）上容易发生显著的精度下滑1 (§3)。

4.1 简单训练后量化的常见失效模式

根据论文分析，针对小模型的简单训练后量化主要面临两类典型问题：

  1. 通道间权重动态范围差异悬殊：同一网络层内不同输出通道的权重范围差异可能超过 100 倍。若整层共享同一套量化参数，权重范围较小的通道分辨率将被严重稀释，产生极大的相对误差；
  2. 权重极值离群点（outliers）：极少数绝对值极大的离群权重会拉宽整体量化区间 [a, b]，导致绝大多数集中在近零区间的权重被挤压在少数几个离散等级上，表征精度大幅下降1 (§3)。

4.2 模拟量化训练（QAT）的运作机制

为了让模型在训练过程中主动适应离散量化带来的截断误差，Jacob et al. (2017) 提出了模拟量化训练（simulated quantization）机制1 (§3)：

在前向传播中，对权重和激活值插入伪量化节点（fake quantization）。定义量化函数 q(r; a, b, n) 如下1 (§3, 式 12)：

clamp(r, a, b) = min(max(r, a), b)
s(a, b, n)     = (b - a) / (n - 1)
q(r; a, b, n)  = round( (clamp(r, a, b) - a) / s(a, b, n) ) * s(a, b, n) + a

其中 [a, b] 为量化范围，n 为量化阶数（8 位量化为 n = 256）。该函数在浮点数值空间中严格模拟离散网格的截断与最近取整效果。

在反向传播与优化阶段：

  • 主干权重保持浮点：优化器中的权重与偏置依然以 FP32 存储并累加微小梯度更新；前向传播模拟量化，反向传播按训练图进行优化1 (§3)；
  • 激活值范围的动态追踪：激活值的动态范围难以提前确定，训练中使用指数移动平均（exponential moving average，EMA）平滑统计其极值边界。同时在训练初期（如前 5 万至 200 万步）关闭激活量化，待参数分布稳定后再开启1 (§3.1)；
  • 批归一化折叠（Batch Normalization folding）：在推理时，批归一化（batch normalization，BN）的均值与方差参数通常会被融合折叠进卷积权重中。为了使训练期的模拟量化与推理行为严格一致，必须在计算伪量化之前将当前的 BN 参数按比例折叠进卷积核1 (§3.2, 式 14)。

5. 实验证据与硬件实测边界

论文（Jacob et al., 2017）的实验验证完全基于经典卷积视觉模型，并在 Qualcomm Snapdragon 移动处理器（835 与 821）的 ARM CPU 上进行了实测1 (§4)。其中准确率评估涵盖 ResNet、Inception v3 与 MobileNet；移动端 CPU 延迟基准主要针对 MobileNet 系列。这些实验数据不是大语言模型（large language model，LLM）的量化实测，而是针对卷积神经网络在移动芯片上的具体评估。

6. 低精度表示的物理边界与权衡

模型量化技术在改善延迟与压缩体积的同时，存在明确的物理边界与工程权衡1 (§5)：

  1. 硬件体系结构与指令集依赖： 延迟—准确率权衡（latency-vs-accuracy tradeoff）高度依赖硬件芯片中整型算术单元与浮点单元的相对吞吐能力。例如在以能效为主的骁龙 835 小核上整型提速较明显，而在对浮点高度专门优化的骁龙 821 上延迟缩减幅度相对较小1 (§4.2.1)；同时张量重定标与对齐也存在开销；
  2. 位宽与精度： 在论文的人脸属性分类消融实验中（Table 4.7），当权重与激活分别在 8 位或 7 位时，精度损失相对有限；但当权重位宽降至 4 位时（如 4 位权重搭配不同激活位宽），平均精度下降幅度显著扩大（相对浮点降幅超过 10%）1 (§4.2.4, Table 4.7)。极低位宽对参数量受限的小模型会带来严重的表征压力；
  3. 训练过程仍保持浮点运算： 论文提出的模拟量化训练方案仍以浮点进行计算与梯度反向传播，并未将离线训练流程改造为纯整数运算。前向伪量化与统计开销是离线阶段的额外计算投入，换取的是部署推理阶段纯整型执行的硬件收益；
  4. 权重存储体积的客观核算： 对相同数量的权重参数，若从 32 位浮点（FP32）换为 8 位整数存储，权重数据本身的物理占用理论上为原来的 1/4；但这一比例仅指权重张量本体，不包含 32 位整型偏置、缩放因子、零点及其他格式元数据，不能作为整模型文件或设备运行内存的无条件倍数保证。

从仿射映射、零点消除到模拟量化训练，Jacob et al. (2017) 确立的整型算术推理范式，为神经网络脱离高功耗浮点硬件单元、走向移动边缘端提供了关键的理论与工程基础。
