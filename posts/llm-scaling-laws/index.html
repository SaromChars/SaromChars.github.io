模型规模与计算预算的分配

2022年5月6日
|

在深度学习领域，大语言模型（large language model，LLM）的预训练（pretraining）通常依托自回归（autoregressive）Transformer 解码器（decoder）架构展开。其工程实践始终面临三项核心约束：可用算力预算、模型参数规模与训练数据量。此前探讨稀疏专家模型时，重点在于通过条件计算解耦参数量与单步浮点运算次数（floating point operations，FLOPs）。而在标准稠密架构下，当研究者获得更多计算预算时，应当如何在扩增模型非嵌入参数与增加处理的 token（模型处理的序列单位，亦称词元）数量之间进行权衡？

Kaplan 等人（2020）在论文《Scaling Laws for Neural Language Models》（arXiv:2001.08361v1）中，通过跨越数个数量级的对照实验，给出了实证层面的定量解答1 (§1)。本文梳理该研究揭示的语言模型缩放规律（scaling laws）、非嵌入参数的统计特性、过拟合边界以及固定算力下的最优分配原则。

1. 规模决定表现与非嵌入参数统计

在自回归文本建模任务中，交叉熵损失（cross-entropy loss，以自然对数计算，通常在 1024-token 上下文内按 token 平均，单位为 nats/token）被作为衡量模型性能的核心指标。在 Kaplan 等人（2020）的研究中，实验覆盖了计算量跨越 8 个数量级、非嵌入参数量跨越 6 个数量级以及数据集规模跨越 2 个数量级的范围（主要基于 WebText2 数据集及标准稠密解码器配置）。实验表明，当模型不受其他资源瓶颈限制时，测试损失会随模型规模、数据规模及计算量的增长呈现出平滑的幂律（power law）下降关系1 (§1.1, §3)。

相比之下，具体的网络架构超参数（如模型深度与宽度的比例、自注意力（self-attention）多头数量、前馈网络维度等）在保持非嵌入参数量固定的前提下，对最终损失的影响非常微弱1 (§3.1, Figure 5)。例如，在保持非嵌入参数量相近时，层数与维度的比例（aspect ratio）即便变化 40 倍，测试损失的变化幅度通常仍在 3% 以内。

1.1 排除词表与位置嵌入的必要性

研究指出，为了获得干净一致的幂律曲线，模型参数量必须统计为非嵌入参数量（non-embedding parameters，记为 N）1 (§2.1)。对于由 n_layer 层构成的标准 Transformer 解码器，设残差流维度为 d_model，中间前馈隐藏层维度 d_ff = 4 * d_model，注意力输出维度 d_attn = d_model，在忽略偏置项（bias）与层归一化（LayerNorm）等次要参数的前提下，其非嵌入参数量近似为：

N ≈ 12 * n_layer * (d_model)^2

模型总参数往往还包含词表嵌入（embedding）矩阵（n_vocab * d_model）以及序列位置嵌入（n_ctx * d_model）。如果在绘制缩放曲线时计入词表嵌入，参数量较小或层数较浅的模型会被庞大的嵌入表严重扭曲，呈现出与深层模型分裂的趋势；而一旦扣除嵌入参数，不同层数与深浅配置的模型几乎全部收敛至同一条平滑的幂律直线上1 (§3.2, Figure 6)。

1.2 单一约束下的三项独立幂律

当训练过程分别只受限于参数量（数据充分）、数据集规模（参数充分）或优化计算量（模型尺寸最优且经批量校正）时，测试损失 L 展现出各自独立的单变量幂律拟合关系1 (§1.2, 式 1.1–1.3)：

变量幂律拟合公式特征指数与主要限定
NL(N) = (N_c / N)^(alpha_N)alpha_N ≈ 0.076，训练至接近收敛
DL(D) = (D_c / D)^(alpha_D)alpha_D ≈ 0.095，采用提前终止
C_minL(C_min) = (C_c_min / C_min)^(alpha_C_min)alpha_C_min ≈ 0.050，远低于临界批量

上述单变量拟合基于 WebText2 数据集测得。其中 C_min 指在批量大小远小于临界批量（B << B_crit）时达成该损失所需的最小非嵌入训练计算量（单位为 PF-days，1 PF-day 对应以每秒 10^15 次浮点运算运行一天，即 8.64 * 10^19 FLOPs）。各拟合的标度常数分别为 N_c ≈ 8.8 * 10^13、D_c ≈ 5.4 * 10^13 以及 C_c_min ≈ 3.1 * 10^8 PF-days；这些常数依赖于分词词表与文本分布，不具通用物理意义。若在固定的常规批量下直接统计总算力 C，其经验拟合指数为 alpha_C ≈ 0.057，标度为 1.6 * 10^7 PF-days。

2. 数据与参数的联立过拟合边界

在实际预训练中，模型参数 N 与训练集 token 数量 D 往往同时有限。如果仅扩大模型规模而不补充数据，模型会过早陷入过拟合；反之，若在较小模型上重复喂入过多数据，模型容量上限又会阻碍损失继续下降。

Kaplan 等人（2020）提出将两项边界统一为双变量联合公式1 (§4.1, 式 1.5)：

L(N, D) = [ (N_c / N)^(alpha_N / alpha_D) + (D_c / D) ]^(alpha_D)

需要说明的是，该公式中的参数为双变量重新联合拟合所得（论文 §4.2 Table 2），对应数值为 alpha_N ≈ 0.076、alpha_D ≈ 0.103、N_c ≈ 6.4 * 10^13 以及 D_c ≈ 1.8 * 10^13，因此其比值为 alpha_N / alpha_D ≈ 0.076 / 0.103 ≈ 0.74，与前述单变量独立拟合的数值略有微调。

该公式表明模型承受的过拟合损失偏差主要由比值 (N^0.74) / D 决定1 (§4.2, 式 4.3)。为了将过拟合引起的损失偏差控制在可忽略水平（测试损失偏离收敛极限不超过 0.02 nats/token），所需的数据集规模与参数量之间满足次线性增长关系1 (§4.2, 式 4.4)：

D >= (5 * 10^3) * N^0.74

这意味着参数量每增长 8 倍（8 ≈ 2^3），训练数据量仅需增长约 4.7 倍（8^0.74 ≈ 4.66），即可避免严重的过拟合。

3. 训练动态与临界批量大小

除了静态参数与数据量外，优化过程中的单步算力与并行度直接决定了训练耗时。

3.1 训练计算量估算

评估标准 Transformer 每次前向传播时，单个 token 消耗的非嵌入计算量约为 2 * N FLOPs（一次乘累加运算按两次浮点运算计）1 (§2.1, 式 2.2)。反向传播因需要计算相对于激活与权重的两组梯度，其计算量约为前向传播的 2 倍。因此，在忽略注意力序列长度项及偏置等次要项的前提下，处理单个 token 的前向加反向总算力可近似表示为：

C_token ≈ 6 * N (FLOPs/token)

设实际训练批量大小为 B 个 token，训练更新步数为 S 次参数更新，则整场训练处理的 token 总次数为 E = B * S。在单轮遍历（single epoch）且不复用数据的假设下，已处理 token 数等于数据集规模（E = D）；整场训练消耗的非嵌入总浮点运算量估计为 C ≈ 6 * N * B * S。

3.2 临界批量大小与学习曲线

利用梯度噪声尺度（gradient noise scale），可以定义训练过程中的临界批量大小（critical batch size，记为 B_crit）1 (§5.1, 式 5.3)：

B_crit(L) ≈ B_* / (L^(1 / alpha_B))

其中 B_* ≈ 2 * 10^8 tokens，alpha_B ≈ 0.21。临界批量大小主要由当前达到的目标损失 L 决定，而与模型的参数量 N 无直接依赖关系。由此可定义两项极限制：在大批量极限（B >> B_crit）下达成目标损失所需的最少更新步数估计为 S_min = S / (1 + B_crit / B)；在小批量极限（B << B_crit）下所需的最少计算量为 C_min = C / (1 + B / B_crit)。当在临界批量（B ≈ B_crit）下训练时，计算量与步数折衷为 C ≈ 2 * C_min 且 S ≈ 2 * S_min。

在无限数据假设下，结合步数校正后，学习曲线展现出统一的幂律形式1 (§5.2, 式 5.6)：

L(N, S_min) = (N_c / N)^(alpha_N) + (S_c / S_min)^(alpha_S)

此处依据论文 §5.2 Table 3 重新拟合，参数为 alpha_N ≈ 0.077，alpha_S ≈ 0.76，N_c ≈ 6.5 * 10^13，S_c ≈ 2.1 * 10^3。

4. 计算预算的最优分配

基于参数量 N 与训练步数 S_min 的联立拟合，论文导出了在给定总算力预算 C_min 下的极值条件。

4.1 经验最优分配幂律

当算力预算增加，若希望在既定计算量下达到最低的测试损失，各变量的最优配比服从如下经验幂律关系（论文 §6.1 式 6.1–6.2 及 Table 6）1 (§6.1, Table 6)：

N_opt ∝ (C_min)^0.73
B_opt ∝ (C_min)^0.24
S_min ∝ (C_min)^0.03
D_opt ∝ (C_min)^0.27

这组幂律揭示了计算预算的最优扩展趋势：在给定的拟合范围与优化假设下，当计算预算扩大 k 倍时，最优模型非嵌入参数量 N 约扩大 k^0.73 倍，而训练处理的 token 总量仅需扩大约 k^0.27 倍。此处假设单遍遍历且不复用数据；在临界批量约定下，B_opt ≈ B_crit 且更新步数为 2 * S_min，实际处理 token 总量为 D_opt = E_opt ≈ 2 * B_crit * S_min，常数因子 2 不改变伸缩指数。由于批量 B 自身以 k^0.24 扩展，串行更新步数 S_min 随计算预算的增长极其平缓（指数仅 0.03，统计上甚至接近于 0）。

需要说明的是，0.73 与 0.27 是幂律增长的比例指数（在对数坐标下两项之和约为 1.0），而非直接将新增算力切分为 73% 与 27% 的资金或资源分账。下图示意了这一并列伸缩关系：

4.2 提前终止的数学推导

传统经验倾向于将模型训练至损失曲线接近平缓收敛。但在纯算力效率的视角下，通过求导极值条件可知，最具算力效率的训练点位于测试损失高出理论收敛极限约 10% 处（f = alpha_N / alpha_S ≈ 0.076 / 0.76 ≈ 10%）1 (Appendix B.2, B.3)：

L(N_eff, C) = (1 + alpha_N / alpha_S) * L(N_eff, ∞) ≈ 1.10 * L(N_eff, ∞)

下表展示了依据论文拟合公式，在假定达到相同目标损失的前提下，对两种提前终止程度（高出收敛极限 2% 与 10%）推算的相对资源需求对比（非具体机房的实测开销）：

评估维度（对齐相同目标损失）传统接近收敛（高出极限 2%）算力最优分配（高出极限 10%）
相对模型参数量 N1.0x（基准相对较小模型）约 2.7x（更大参数规模）
相对更新步数 S1.0x（迭代充分）约 0.13x（减少约 7.7 倍）
所需训练总计算量 C1.0x（基准计算开销）约 0.35x（节省约 65% 计算量）

大模型表现出更高的样本效率（sample efficiency）：它只需要更少的更新步数即可达到小模型长时间训练至接近收敛才能达到的损失。因此，在节省预训练计算 FLOPs 的单一目标下，使用更大参数量的模型并在收敛前提前终止更为高效。

5. 跨分布泛化与工程权衡边界

上述缩放规律在论文探索的数个数量级内具有良好一致性，但在将其推广到真实生产与工程决策时，必须审慎识别其前提假设与机制边界。

5.1 领域外迁移的恒定偏移

研究者将 WebText2 上训练的模型在 BooksCorpus、Common Crawl 及英文维基百科等其他文本分布上进行测试，发现测试损失与训练集验证损失呈现强相关，且同样遵循平滑的幂律1 (§3.2.2, Figure 8)。

跨分布迁移主要表现为一个较小且可能随模型规模缓慢增长的正向偏移量（offset），该偏移量主要由模型在训练集上达到的损失水平决定，而与模型层数深浅无明显依赖。这表明在所测文本分布范围内，降低预训练交叉熵损失能稳定转化为对应语料上的语言建模改善，但该结论仅限于文本交叉熵指标，不能直接推广为下游具体任务的回答质量或事实真实性保证。

5.2 训练算力与推理成本的冲突

Kaplan 等人（2020）的最优算力推导仅针对预训练阶段的 FLOPs 消耗，并未将下游部署阶段的推理（inference）成本纳入目标函数1 (Appendix B.4)。

在实际落地中，模型每生成一个 token，其前向计算主要由参数量 N 决定。若服务面临海量长期的线上推理请求，使用大模型带来的持续推理计算负担可能会削弱预训练阶段节省的算力收益。

选型取向与考量偏离最优尺寸比例训练与推理的影响（估算）
倾向缩短串行训练步数选取 2.2x N_eff步数少 45%，训练算力增约 20%
兼顾部署与推理计算需求选取 0.6x N_eff训练算力增约 20%，推理前向主导 FLOPs 约降至 0.6 倍

论文在附录 B.4 中推导指出，在最优尺寸 N_eff 的 0.6 倍至 2.2 倍区间内，达成同等目标损失所需的训练总算力增幅不超过 20%。如果下游推理需求巨大，选用偏小尺寸（如 0.6x）能有效降低推理阶段的前向计算需求；若硬件允许足够的数据并行，采用偏大尺寸（如 2.2x）则能以增加 20% 算力为代价减少 45% 的串行更新步数，从而可能缩短训练耗时（该推导仅适用于初始瞬态之后的幂律区间）。

5.3 机制失效与理论边界

在以下特定场景中，上述幂律的适用性将面临失效1 (Appendix C, §6.3)：

  1. 长上下文的计算项偏离： C_token ≈ 6 * N 的前提是上下文长度满足 d_model >> n_ctx / 12。当处理超长上下文使得注意力矩阵计算的 2 * n_layer * n_ctx * d_model 成为重要项时，纯基于参数量的近似会低估实际计算量。
  2. 极小数据样本区间的偏离： 对于非常小的数据集（如仅约 2000 万 token，每轮仅约 40 次更新），原论文指出过拟合发生很早，其学习曲线与联合幂律拟合存在明显偏差。
  3. 极端外推下的数据瓶颈矛盾： 由于最优数据量按 D ∝ C^0.27 缓慢增加，若将该公式向外推算至极大尺度（约 10^12 参数、10^4 PF-days 时），外推得到的计算最优损失将低于有限数据拟合所允许的下界，说明这些幂律关系不能同时无限外推；且该交点数值对拟合指数高度敏感，上下可能相差一个数量级。作者另提出一种未经证实的推测：该交点也许接近自然语言每 token 的信息熵下限，据此损失曲线才可能在达到交点前趋于平缓。
  4. 超参数优化的固定假设： 实验中超过 10 亿参数（> 1B）的最大模型改用了 Adafactor 优化器，而较小模型主要使用 Adam 与余弦退火；此外，学习率调度与权重初始化方差等超参数在不同规模间并未逐一全面调优，潜在的超参数敏感性可能对局部拟合斜率产生影响。
