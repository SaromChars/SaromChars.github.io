多模态文本与图像的表征对齐

2022年4月11日
|

承接此前关于大语言模型（large language model，LLM）通过自回归生成预测下一 token（模型处理的基本序列单位，词元，可对应子词、字符或字节等单位）以及接入外部程序的讨论，这里把讨论扩展到连续图像，关注离散文本与视觉输入的表征对齐。

在传统的计算机视觉体系中，模型通常依赖预设的离散类别标签进行有监督训练（training）；若要适配新概念，系统通常需要针对新标签重新组织训练或调整分类头。要让计算机直接比较图像内容与自然语言描述，核心在于建立文本与视觉之间的跨模态表征对应关系。

2021 年，Radford et al. 提出了 CLIP（Contrastive Language-Image Pre-training）架构1。该研究通过在 4 亿图文对的大规模互联网数据集上进行双编码器对比预训练（pretraining），展示了利用自然语言监督直接学习可迁移视觉表征的可行路径。本文基于该论文的固定版本，说明文本与视觉输入的连接机制、对比学习与生成预测在该研究中的计算能效权衡、零样本分类的向量检索本质，以及跨模态对齐在抽象推理与分布外数据上的局限与边界。

1. 跨模态表征映射与方案选择

要让计算机系统同时理解图像与文本，最直观的挑战在于两种模态的数据结构存在根本差异：文本是由分词器（tokenizer，通常处理子词、字符或字节）切分出的离散符号序列，而图像是由连续像素网格构成的密集多维张量。连接两者的核心任务，是在隐层空间中找到一种联合嵌入空间（joint embedding space），使得语义相近的图像嵌入（embedding）与文本嵌入在向量空间中距离接近。

图外说明与技术路线对比：

  • 方案 A（自回归生成式描述，如 VirTex）：图像经视觉编码器提取特征后，由解码器逐词自回归生成文本；论文指出图文描述多样使精确词预测更困难，且该组基线算力消耗显著高于对比目标。
  • 方案 B（双编码器对比对齐，CLIP 范式）：图像与文本分别经独立编码器和线性投影映射到同一联合嵌入空间，直接计算标量积；在论文实验中，仅判断图文是否成对匹配，零样本迁移效率较词袋预测基线提升 4 倍。

1.1 自回归文本生成的效率瓶颈

在探索自然语言监督时，早期工作（如 VirTex）通常采用编码器—解码器（encoder-decoder）架构：利用卷积神经网络提取图像特征，再由基于 Transformer（一种基于自注意力机制的模型架构）的解码器逐个预测图像的对应文本描述（Image Captioning）1 (§2.3)。

然而，Radford et al. 在实验中发现，这种生成式目标在规模化扩展时遭遇了计算效率瓶颈：

  1. 模型算力开销：一个拥有 6300 万参数的 Transformer 语言模型，其算力消耗已经是 ResNet-50 视觉编码器的 2 倍；
  2. 文本表述的多样性：论文指出，互联网图像附带的旁注文本存在大量主观修饰与风格差异，强迫模型精确预测具体的每个词会使预测任务格外困难。

实验数据显示，在该研究测试的基线上，仅预测文本中词袋（Bag-of-Words）编码的简化模型，在 ImageNet 零样本识别上的学习速度比自回归逐词生成快 3 倍；而如果将预测词袋的目标替换为图文匹配的对比学习（contrastive learning）目标，在同一指标上的零样本迁移效率会在词袋基线的基础上进一步提升 4 倍1 (§2.3, Figure 2)。

1.2 联合嵌入空间的线性投影

基于上述发现，CLIP 确立了双编码器解耦架构。系统包含两个独立的特征提取骨干：

  • 图像编码器（Image Encoder）：支持改进型 ResNet（采用注意力池化 Attention Pooling 替代全局平均池化）或视觉 Transformer（Vision Transformer，ViT）1 (§2.4)；
  • 文本编码器（Text Encoder）：基础尺寸（base size）为 12 层、512 隐藏层维度、8 个注意力头的 Transformer，处理经字节对编码（byte pair encoding，BPE）切分的文本序列，提取特定位置（[EOS] token）的最高层隐层状态作为文本全局特征；文本编码器的宽度随视觉模型缩放1 (§2.4)。

在图像自监督表征学习（如 SimCLRv2）中，研究界通常在编码器后添加多层感知机（multilayer perceptron，MLP）非线性投影头。但在跨模态图文对齐中，Radford et al. 在实验中没有观察到非线性投影与线性投影在训练效率上的显著差异，因此最终采用简化的线性投影层（Linear Projection）将视觉特征与文本特征分别映射到同一维度的联合嵌入空间1 (§2.3)。

2. 双编码器对称对比学习机制

CLIP 的核心思想是将开放文本理解任务，转化为一个代理判别问题：在一个包含多个图文对的批量中，判断哪一张图片与哪一段文字原本是成对共现的1 (§2.3)。

批次内图文相似度计算与对称对比损失流程：

  1. 双模态嵌入矩阵计算：
    • 包含 N 个样本对的图像批次与文本批次分别输入编码器，经投影与归一化后得到特征矩阵 I 与 T（尺寸均为 N × d）；
    • 计算成对缩放相似度矩阵：S = (I · T^T) * exp(logit_scale)，矩阵规模为 N × N。
  2. 正负样本与损失分配：
矩阵位置配对关系与性质交叉熵优化目标
对角线元素 S_ii真实共现的正样本对极大化同索引图文相似度
非对角元素 S_ij批内随机组合负样本对相对抑制未配对样本相似度
按行与按列计算图搜文与文搜图双向约束行交叉熵与列交叉熵各取均值后平分（权重各 0.5）

2.1 批量构造与对称交叉熵损失函数

假设单个训练微批次（minibatch）总规模为 N 个配对的样本 (image_i, text_i)。

  1. 视觉编码器与文本编码器分别输出特征，经线性投影和 L2 归一化后得到单位向量 v_i 与 t_i（维度均为 d）；
  2. 在该批次内，系统可以组合出 N * N 个潜在的图文对，其中对角线上的 N 个样本为真实共现的正样本对（positive pairs），其余 N^2 - N 个非对角元素为批次内配对标签意义上的负样本对（negative pairs）；
  3. 计算所有图像向量与文本向量的余弦相似度，并乘以温度调节因子 1 / τ（即 exp(logit_scale)）。

为了同时约束图到文与文到图的双向检索，模型采用对称多类交叉熵损失（Symmetric Cross Entropy Loss）1 (§2.3)：

图像到文本的分类损失（按行归一化）：
L_{img} = - (1 / N) * ∑_{i=1}^N log [ exp(cos(v_i, t_i) / τ) / ∑_{j=1}^N exp(cos(v_i, t_j) / τ) ]

文本到图像的分类损失（按列归一化）：
L_{txt} = - (1 / N) * ∑_{j=1}^N log [ exp(cos(v_j, t_j) / τ) / ∑_{i=1}^N exp(cos(v_i, t_j) / τ) ]

全局对称优化目标：
L = (L_{img} + L_{txt}) / 2

2.2 可学习温度系数与超大批次工程

在对比学习中，温度参数直接控制 softmax 概率分布的平滑度。Radford et al. 令可学习参数 logit_scale 的初始值为 log(1 / 0.07)，使用乘法标量 exp(logit_scale) 缩放相似度（有效温度 τ = exp(-logit_scale)，初始为 0.07）。论文报告在训练过程中将对数几率的缩放因子裁剪至不超过 100，用于防止训练不稳定1 (§2.5)。

为了让对比学习接触到丰富的负样本，CLIP 采用了高达 32,768 的总微批次规模（minibatch size）。在工程实现中，这依赖于多项系统级优化1 (§2.5)：

  • 混合精度训练与内存优化：采用 FP16 混合精度计算，配合梯度检查点（Gradient Checkpointing）技术，减少保存中间激活、以重算换显存；
  • 分片相似度计算（Sharded Similarity Calculation）：各 GPU 按局部批次所需相似度分片计算局部成对相似度，避免在单机节点维护全局稠密矩阵。

3. 跨模态零样本迁移

在传统设置中，零样本学习（Zero-Shot Learning）多聚焦于未见类别间的迁移。CLIP 的评测方式则是直接利用预训练模型评估跨数据集的任务泛化能力1 (§3.1.1)：将图像分类重构为图像向量与一组预先指定的候选文本描述之间的最近邻语义匹配1 (§3.1.2)。

零样本图像分类工作流：

  1. 文本提示词编码（离线预先计算并缓存）：
    • 给定待分类标签集（如 "dog", "cat", "car"），构造提示模板 "A photo of a {label}."；
    • 文本编码器提取特征后经线性投影与 L2 归一化，生成类别权重矩阵 W_text（维度 K × d）；在类别与提示不变时缓存复用。
  2. 图像特征提取（在线推理，inference）：
    • 输入测试图像，经视觉编码器提取特征并完成线性投影与 L2 归一化，得到图像嵌入向量 v（维度 1 × d）。
  3. 余弦相似度判别与预测：
    • 计算图像向量与所有候选文本权重的点积并施加温度缩放：logits = (v · W_text^T) * (1 / τ)；
    • 输出预测类别：预测类别 = argmax(logits)。

在这种视角下，文本编码器扮演了超网络（Hypernetwork）的角色：根据自然语言书写的概念描述，动态合成下游线性分类器的权重参数 W_text1 (§3.1.2)。

3.1 提示词工程与嵌入空间集成

在零样本迁移中，直接输入孤立类别名称（如 "boxer" 或 "crane"）往往会导致性能受损，主要由于一词多义（polysemy，例如起重机与鹤）以及预训练文本多为完整句子的分布差异1 (§3.1.4)。

为此，研究团队提出了提示词工程（prompt engineering）：使用标准化模板 "A photo of a {label}." 包裹类别名称。仅此一项改动，便直接使 ImageNet 的零样本分类准确率提高约 1.3 个百分点1 (§3.1.4)。针对特定数据集补充先验提示（如 Oxford-IIIT Pets 的 "..., a type of pet." 或光学字符识别（optical character recognition，OCR）中的引号标注）也能进一步改善表征匹配。

进一步地，研究者提出了嵌入空间集成（Prompt Ensembling）：编写 80 个不同的上下文提示模板，分别计算文本嵌入后在向量空间取平均值，再经归一化得到最终分类权重。在 ImageNet 上，该集成策略相比单个默认提示可进一步提升约 3.5 个百分点，提示词工程与集成累计使准确率提高约 4.8 个百分点1 (§3.1.4, Figure 4)。由于系统可以先离线生成并缓存平均文本权重，在类别与提示不变时，每张后续图像无需额外运行 80 次文本编码器。

3.2 零样本迁移性能与少样本对比

在 27 个标准视觉基准测试集的系统评估中，未经微调的零样本 CLIP 在 16 个数据集上的表现超越了在标准 ResNet-50 特征上训练的完全有监督线性分类器1 (§3.1.5, Figure 5)。在最强模型 ViT-L/14@336px 上，其 ImageNet 零样本准确率达到 76.2%（top-5 达 95%），匹配了原版 ResNet-50 有监督基准。

在少样本对比中，在评估集中每类至少包含 16 个样本的 20 个数据集的平均结果上，零样本 CLIP 的表现持平了在相同特征空间上训练的 4-shot 线性探测（Linear Probe）模型，并大致接近评估集中公开模型表现最佳的 16-shot 分类器（在 ImageNet-21K 上预训练的 BiT-M ResNet-152x2）1 (§3.1.5, Figure 6)。作者推测，直接用自然语言描述指定概念可能减少仅从少数几张图像示例中归纳视觉概念所面临的多义性与假设歧义1 (§3.1.5)。

4. 多模态表征对齐的局限

尽管双编码器对比对齐展现了可观的迁移表现，但该范式在底层机制上仍有明确局限1 (§6)。

4.1 判别式闭环匹配并非开放生成

本文采用的零样本分类协议要求在预先给定的候选文本标签集合中做比选，输出限于本次给定的候选概念1 (§6)。 CLIP 本身是一个双编码器表征对齐模型，不具备自回归语言生成能力，无法直接输出自由组合的开放式自然语言长句或解释。

4.2 细粒度、抽象关系与结构化推理缺陷

实验表明，零样本 CLIP 在多项高度专业化或需要组合推理的任务上表现较弱1 (§3.1.5)：

  1. 细粒度分类：在区分具体卫星遥感地貌（EuroSAT、RESISC45）、特定花卉品种（Flowers102）或变体机型（FGVCAircraft）时，性能落后于有监督基线；
  2. 几何与抽象任务：在合成场景计数任务（CLEVRCounts）以及自动驾驶相关距离估计（KITTI Distance）等任务上，零样本表现较弱，部分任务接近随机猜测水平；
  3. 专业医疗病理：论文的零样本 CLIP 在淋巴结肿瘤病理切片检测（PatchCamelyon）上表现较弱；作者提醒，对缺乏相关任务先验经验的学习者，如何解释此类困难任务的零样本评测仍需谨慎1 (§3.1.5)。

4.3 分布外脆弱性与数据覆盖

论文的 CLIP 在多个自然分布偏移测试集上有良好表现，但作者仍观察到其在真正分布外数据上泛化较弱1 (§3.3, §6)。

在光学字符识别（OCR）任务中呈现了鲜明对比：

  • 在数字渲染文本情感数据集（Rendered SST2）上，零样本 CLIP 有一定表现（ViT-L/14@336px 准确率为 67.9%）；
  • 但在经典的 MNIST 手写数字数据集上，该模型的识别准确率仅为 88.3%，被基于原始像素训练的简单逻辑回归基线击败1 (§6, Appendix E)。

检索分析显示，预训练数据中几乎没有类似 MNIST 样式的手写灰度数字。作者据此认为，这些观察提示 CLIP 可能仍未解决深度学习的脆弱泛化问题；用更大、更多样的数据覆盖潜在场景，不能保证所有输入都处于训练分布内1 (§6)。

4.4 数据利用率与社会偏见

CLIP 模型的预训练大多历经 32 个完整 epoch，累计前向计算了约 128 亿张次图像（若以每秒 1 张图片的速度浏览，约需 405 年）1 (§6)；最强模型 ViT-L/14@336px 还在高分辨率下额外微调训练了 1 个 epoch1 (§2.5)。

此外，直接从互联网收集的大规模图文对包含未经清洗的社会偏见与刻板印象。在 FairFace 等人脸属性分类探测中，零样本与线性探测均展现出不同程度的人口学偏见与非对称错误率1 (§7, Table 3, Table 4)。

5. 总结

通过视觉与文本双编码器及对称对比目标，系统成功在联合嵌入空间中将连续图像与离散文本连接起来，把分类问题转化为候选语义的向量检索。然而，图文配对与闭环分类上的匹配能力，不能等同于模型已经掌握了开放环境下的自主文本生成或可靠的组合抽象推理。
