Transformer为什么需要Attention？从《Attention Is All You Need》读起

2022年3月4日
|

在序列转导（Sequence Transduction）任务——特别是机器翻译中，模型需要处理词与词之间跨越长距离的依赖关系。例如在句子“The animal didn’t cross the street because it was too tired”中，要准确翻译代词“it”，模型必须推断它究竟指代前面的“animal”还是“street”。

在 2017 年之前，主流的序列模型依赖循环神经网络（RNN、LSTM 或 GRU）。这类网络沿着时间步逐步推进计算：当前位置的隐藏状态依赖于前一位置的隐藏状态。这种按顺序推进的机制带来了两项制约：第一，相距较远的词之间，信号必须跨越多个循环步依次传递，长程信息容易在逐步递归中损耗；第二，在训练时，第 t 步的计算必须等待第 t-1 步完成，无法沿序列长度方向展开并行计算。虽然卷积神经网络（如 ConvS2S、ByteNet）允许各位置并行计算特征，但要建立远距离词之间的关联，需要堆叠多层卷积逐步扩大感受野，两点之间的交互路径长度仍随距离线性或对数增长。

2017 年，Ashish Vaswani 等人在 6 月首次提交、12 月修订的论文《Attention Is All You Need》1 中，提出了一种抛弃循环与卷积的架构——Transformer。它的核心思想是通过自注意力机制（Self-Attention），让序列中任意两个位置之间只需一步直接交互即可建立联系。在当前语言模型体系中，Attention 已成为基础结构；但要理解它的工作方式，需要先回到原论文的推导起点。

自注意力与 Q、K、V 角色投影

在传统 Seq2Seq 模型中，注意力机制通常用于连接编码器与解码器；而在 Transformer 中，自注意力被用来在同一序列内部计算各位置之间的上下文表示。

从数学抽象来看，注意力函数的作用是将一个查询向量（Query）和一组键值对（Key-Value pairs）映射为一个输出向量。输出结果是这组值向量（Values）的加权求和，而赋予每个 Value 的权重，则取决于 Query 与对应 Key 的匹配程度。

为什么同一个输入词需要拆分出 Query、Key 和 Value 三种表示？

对于输入序列的隐藏状态矩阵 X（维度为 n × d_model），单头注意力在概念上使用三个可学习的线性投影矩阵 W^Q、W^K、W^V 对其进行变换，分别得到：

Q = X * W^Q  (查询矩阵)
K = X * W^K  (键矩阵)
V = X * W^V  (值矩阵)

这三种投影赋予了同一个词不同的功能职责：

  • Query（查询）：代表当前位置主动发出的“寻址请求”，负责向其他位置查询与自己相关的信息。
  • Key（键）：代表当前位置向外暴露的“索引特征”，用于响应其他位置的 Query 匹配。
  • Value（值）：代表当前位置所包含的“实质内容”，一旦匹配成功，这部分内容将按权重汇入最终表示中。

同一个词在序列中具有多重角色：它既需要作为观察者去检索上下文（Query），也需要作为被观察对象供其他词检索（Key），同时还要提供自己的语义信息（Value）。如果直接用未经投影的原始向量做内积与加权，这三重角色将被迫共享同一套特征空间，限制了模型捕捉复杂依赖的能力。

需要明确区分的是，在自注意力中，Q、K、V 来自同一个序列的上一层输出；而在后文提到的跨注意力（Cross-Attention）中，Q 来自解码器内部当前交叉注意力子层前一步的输出，而 K 和 V 则来自编码器栈顶部的最终输出表示。

缩放点积注意力：计算过程与示意

原论文采用的具体计算形式被称为“缩放点积注意力”（Scaled Dot-Product Attention）1 (Vaswani et al., §3.2.1)：

Attention(Q, K, V) = softmax( (Q * K^T) / sqrt(d_k) ) * V

整个计算包含四个步骤：

  1. 计算兼容性得分：将 Query 矩阵与 Key 矩阵的转置相乘（Q * K^T），得到各位置两两之间的点积。点积同时受向量方向与模长的影响，并非归一化的余弦相似度。在其他得分固定的前提下，点积数值越大，表明兼容性得分越高，后续分配到的 Softmax 权重也越高。
  2. 缩放因子 sqrt(d_k)：如果键向量的维度 d_k 较大，假设 q 和 k 的各分量是均值为 0、方差为 1 的独立随机变量，其点积的方差就会增长至 d_k。当点积方差过大时，得分之间的差距容易被拉大，导致经过 Softmax 计算后的概率分布趋向两极，使得梯度处于极平缓的饱和区域。为了抵消这种方差放大效应，论文将点积除以 sqrt(d_k)，使数值分布更加平稳。
  3. 逐行 Softmax 归一化：对每一行（即针对每个 Query）的得分进行 Softmax 处理，将原始得分转换为一组非负且和为 1 的权重系数。
  4. 与 Value 加权求和：用 Softmax 得到的权重对 Value 矩阵进行加权组合，得到当前层融合了上下文信息的最终输出。

为了直观展示这一过程，以下构造一个简化的人为数值示意（注：本例纯属为了展示矩阵流向而手工设定的示意数据，非真实模型测试结果，亦非真实分词器输出）：

假设序列中有 3 个词项：["The", "animal", "tired"]，设定特征维度 d_k = 2。

对于词项 "tired" 发出的查询向量 q_3 = [1.0, 0.5]，它与序列中 3 个词项的 Key 向量分别做点积并除以缩放因子 sqrt(2) ≈ 1.414：

词项 (i)Key 向量 (k_i)点积 (q_3 · k_i)缩放后得分 (/ 1.414)Softmax 权重
1. “The”[0.2, 0.1]0.250.180.19
2. “animal”[1.2, 0.8]1.601.130.49
3. “tired”[0.8, 0.4]1.000.710.32

从计算结果可见，查询词 "tired" 与 "animal" 的兼容性最高，分得了约 0.49 的权重，自身保留约 0.32，对 "The" 分配约 0.19。最后将各词的 Value 向量按此权重求和：

Output_3 ≈ 0.19 * v_1 + 0.49 * v_2 + 0.32 * v_3

这样，词项 "tired" 的新表示就动态吸收了来自 "animal" 的关键信息。

多头注意力：拓展表征子空间

如果只用单头注意力，对于每个Query位置，各特征维度共享同一组对各Key位置的权重；用这组权重对不同位置的Value向量做加权求和，很难同时保持不同类型的相对依赖（例如句法搭配、指代关联与相邻修饰）1 (Vaswani et al., §3.2.2)。

为此，Transformer 提出了多头注意力（Multi-Head Attention）：

MultiHead(X) = Concat(head_1, ..., head_h) * W^O  (本节自注意力情形)
其中 head_i = Attention(X * W_i^Q, X * W_i^K, X * W_i^V)

在原论文的基础配置中，模型采用 h = 8 个并行注意力头。对于输入表示矩阵 X（n × d_model，其中 d_model = 512），每个头直接使用独立的投影矩阵进行线性映射：

W_i^Q ∈ R^(d_model × d_k)
W_i^K ∈ R^(d_model × d_k)
W_i^V ∈ R^(d_model × d_v)

其中设定投影维度 d_k = d_v = d_model / h = 64。每个头在各自的 64 维子空间中独立计算注意力，生成维度为 n × d_v（即 n × 64）的输出；随后将 8 个头的输出在特征维度上拼接为 n × (h · d_v) = n × 512 的矩阵，最后通过输出投影矩阵 W^O ∈ R^(512 × 512) 整合为最终的 n × d_model 输出。由于每个头的维度缩小为原来的 1/8，8 个头并行计算的总计算量与全维度的单头注意力大体相当。

需要注意的是，论文作者在附录中观察到，不同注意力头在训练后呈现出不同的关注倾向，有的关注动宾关系，有的关注代词指代。但这属于多子空间联合表征经验性涌现出的结果，并不代表网络结构在数学上强行保证“第 1 个头必然学习句法、第 2 个头必然学习词性”。将注意力权重直接解读为模型确凿的语法规则或因果解释，超出了该机制本身的数学保证。

为什么自注意力天生不知道词序？

在不包含位置编码且没有依赖位置的固定掩码前提下，自注意力运算具有一项固有特征：置换等变性（Permutation Equivariance）。

具体而言，对于任意置换矩阵 P，若将输入矩阵行置换为 P * X，自注意力层函数的输出相应地满足 F(P * X) = P * F(X)，其内部的注意力权重矩阵 A 也会变换为 P * A * P^T。这意味着词与词之间的对应注意力权重保持不变，只是伴随序列顺序同步重排。自注意力运算本身无法感知词项在序列中的绝对与相对先后次序。

自然语言的语义高度依赖词序。为了让模型能够区分先后，原版 Transformer 在输入端将词嵌入（Token Embedding）与位置编码（Positional Encoding）直接相加注入顺序信息 1 (Vaswani et al., §3.5)：

X_input = Token_Embedding + Positional_Encoding

原论文采用正弦与余弦交替的周期函数生成固定位置编码：

PE(pos, 2i)   = sin( pos / (10000^(2i / d_model)) )
PE(pos, 2i+1) = cos( pos / (10000^(2i / d_model)) )

其中 pos 表示词在序列中的绝对位置，i 表示特征维度的索引。选择三角函数的一个依据是：对于任意固定的相对偏移 k，PE_{pos+k} 都可以表示为 PE_{pos} 的线性函数，这有助于模型推断相对位置。论文也对比了可学习的位置嵌入，实验显示两者翻译表现相当，而三角函数方案具备推断超出训练长度序列的潜在可能。

原版 Encoder-Decoder 结构与运行边界

2017 年的 Transformer 并不是一个纯解码器（Decoder-only）文本生成模型，而是一个标准的编码器—解码器（Encoder-Decoder）结构，专为机器翻译设计 1 (Vaswani et al., §3.1, §3.2.3)。

整个网络由编码器栈和解码器栈构成，原论文各堆叠了 N = 6 层：

  • 编码器（Encoder）：每层包含两个子层：
    1. 多头自注意力机制（Self-Attention）；
    2. 逐位置前馈网络（Position-wise Feed-Forward Network，由两层线性变换和 ReLU 构成，d_ff = 2048）。 每个子层外都包含残差连接（Residual Connection）和层归一化（Layer Normalization）。
  • 解码器（Decoder）：每层包含三个子层：
    1. 带因果掩码的多头自注意力（Masked Self-Attention）；
    2. 编码器—解码器交叉注意力（Cross-Attention）：Query 来自解码器当前层中此前自注意力子层的输出，Key 和 Value 取自编码器栈顶部的输出表示；
    3. 逐位置前馈网络，附带残差连接和 LayerNorm。

这里涉及训练阶段与推理阶段的关键运行机制区别：

在训练阶段，为了防止解码器在预测第 i 个目标词时提前看到真实标签，原论文设计了双重防护：目标序列右移（Offset by one position）与因果掩码（Causal Masking）。训练时解码器的输入序列是在真实目标序列前端添加起始符号并右移一位（例如输入 [<BOS>, y_1, y_2, ...] 来监督预测 [y_1, y_2, y_3, ...]）。在此基础上，因果掩码在计算 Softmax 之前将未来位置的注意力得分设为负无穷，确保预测第 i 个位置的目标时，注意力只能覆盖该位置此前的已知目标。由于训练时监督数据完整已知，整个目标序列的所有位置可以在单次前向传播中并行计算损失。

而在推理生成阶段，模型无法预先知道后续的输出内容。解码器必须采用自回归（Auto-Regressive）方式逐步生成：先依据源句和起始符预测第 1 个词，再将生成的词追加到解码器输入中去预测第 2 个词，单步推进直至生成终止符。训练时的位置并行不等于推理时的整句单步生成。

后续以 GPT-3（Brown et al., 2020）2 为代表的生成模型，在架构上采用了纯解码器（Decoder-only）形式：移除了编码器和交叉注意力子层，由多层带因果掩码的自注意力、前馈网络（FFN）、残差连接和层归一化堆叠而成。2017 年的原版 Transformer 是面向 Seq2Seq 翻译任务的编码器—解码器设计，不能将其与后续的纯解码器大语言模型架构混为一谈。

计算复杂度的收益与现实代价

Transformer 常被视作克服了序列串行计算的瓶颈，但这种计算特征伴随着具体的复杂度边界。原论文在第 4 节通过 Table 1 对比了不同网络层的计算性质 1 (Vaswani et al., §4)：

层类型 (Layer Type)单层计算复杂度 (Complexity per Layer)串行操作步数 (Sequential Operations)最大路径长度 (Maximum Path Length)
自注意力 (Self-Attention)O(n^2 · d)O(1)O(1)
循环层 (Recurrent)O(n · d^2)O(n)O(n)
卷积层 (Convolutional)O(k · n · d^2)O(1)连续卷积 O(n/k)，扩张卷积 O(log_k n)

从表中可以看到两项理论优势：

  1. 最大路径长度为 O(1)：循环网络在两点间传递信息需要 O(n) 步，核宽度为 k 的连续卷积需要 O(n/k) 层、扩张卷积需要 O(log_k n) 层，而自注意力在单层内即可让任意两个位置直接交互，缩短了长程依赖的信号传递路径。
  2. 串行步数为 O(1)：自注意力计算不依赖时序递归，各位置操作可直接向量化并行。

但在单层复杂度上，自注意力是 O(n^2 · d)，而循环层是 O(n · d^2)。

论文指出：当序列长度 n 小于表征维度 d 时，自注意力层在每层理论操作数上少于循环层。然而，理论渐近复杂度并不直接等同于工程实际中的执行时间或显存开销。标准全注意力需要实例化并计算一个 n × n 的注意力权重矩阵，其实际运行成本与表征维度 d 的具体取值、底层矩阵算子实现、显存访问瓶颈以及硬件架构密切相关。全量自注意力关于序列长度 n 的二次方复杂度，使其在长序列扩展时面临显著的算力与存储代价，并不能无条件概括为在任何场景下都更轻量或更高效。

总结

《Attention Is All You Need》的关键突破，在于证实了仅依靠注意力机制与前馈网络的协同，即可建立高质量的序列全局依赖。它通过 Q、K、V 线性投影解耦功能角色，通过除以 sqrt(d_k) 稳定点积分布，通过多头机制拓宽表征子空间，并通过位置编码补充了词序信息。

然而，注意力机制本身并不产生输入向量——在这些矩阵运算发生之前，文本必须先被转化为离散的符号与数值向量。分词器如何切分词项、嵌入层如何为符号赋予连续空间表示，构成了 Transformer 消化语言的第一道关卡。
